# Armes : identifiant de code et nom en jeu

Les identifiants (`id` des `.tres`, fichiers `data/weapons/<id>.tres`, `assets/icons/weapons/<id>.png`) sont **stables** : ils sont dans les sauvegardes et les défis, on ne les renomme pas (CLAUDE.md). Plusieurs ne correspondent plus au nom affiché (l'arme a été rebaptisée en cours de route). Cette table fait foi pour les échanges : **on parle des armes par leur nom en jeu**.
